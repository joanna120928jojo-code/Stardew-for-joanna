Hello! First of all, thank you for downloading the file I made.
This is a small Stardew Valley mod I made to make the game a little more peaceful and relaxing. I wanted to reduce some of the stress caused by combat and time limits so that I could enjoy Stardew Valley at my own pace.

The current features are as follows:
* Monster attacks do not reduce the player's health.
* The player's health is automatically restored to its maximum value.
* In-game time stops when it reaches 11:00 PM (23:00).
* This mod does not disable monster behavior itself, so monsters such as slimes may still approach or attack the player. However, damage from monsters will not be applied.

SMAPI is required to run this mod.
The mod should be installed at:
SteamLibrary\steamapps\common\Stardew Valley\Mods[Joanna] Peaceful Stardew
If the mod has been downloaded in the folder structure shown above, the installation should be complete.
Once installed, you do not need to change anything else. Simply launch Stardew Valley, and the features I have set up will be applied automatically.

As this is my first Stardew Valley SMAPI mod, there may be unexpected errors or issues. If you encounter any problems, please leave a comment on the post where this mod was shared so that I can check the issue.
